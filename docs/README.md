# AAgent 文档索引

AAgent 是一个受 CPU 执行循环启发的事件脉冲驱动 Agent 运行时。当前以 QQ 作为过渡事件源,未来以 WebUI 作为主要交互与事件入口。文档按职责拆分,替代原根目录的《业务逻辑文档.md》《架构文档.md》。

| [00-设计哲学](00-设计哲学.md) | CPU 执行模型、事件脉冲、串行原则、WebUI-first 演进方向 | 了解项目定位与长期设计 |
| [01-系统架构](01-系统架构.md) | 服务拓扑、事件驱动设计、数据存储 | 架构评审、新成员入门 |
| [02-事件与队列](02-事件与队列.md) | 事件类型、状态机、队列优先级机制、典型流转 | 修改 worker / 队列逻辑 |
| [03-模块详解](03-模块详解.md) | 各服务/模块职责与接口(qqbot / agent / llm / tool / qqapi / history / webui) | 修改业务代码 |
| [04-配置与部署](04-配置与部署.md) | 环境变量、Docker Compose、目录结构、安全 | 部署与运维 |
