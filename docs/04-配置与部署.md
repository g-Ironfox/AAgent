# 04 配置与部署

## 1. 环境变量(模板见根目录 `.env.example`)

### LLM 与工具

| 变量 | 说明 |
|------|------|
| `DEEPSEEK_BASE_URL` / `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | DeepSeek 地址 / Key / 模型名(默认 `deepseek-v4-pro`) |
| `KIMI_BASE_URL` / `KIMI_API_KEY` | Moonshot Kimi 地址 / Key |
| `ZAI_API_KEY` | 智谱/GLM Key(当前未在主线使用) |
| `TAVILY_API_KEYS` | Tavily 搜索 Key,逗号分隔多个,自动轮询 |
| `BOCHA_BASE_URL` / `BOCHA_API_KEY` | 博查搜索地址 / Key |

### QQ 连接

| 变量 | 说明 |
|------|------|
| `QQ_API_BASE_URL` / `QQ_API_TOKEN` | QQ HTTP API 地址 / Token(发消息等) |
| `QQ_WS_URI` / `QQ_WS_TOKEN` | QQ WebSocket 事件地址 / Token |
| `QQ_TARGET_USER_ID` | 授权触发 LLM 的用户 QQ 号 |
| `QQ_BOT_ID` | 机器人自身 QQ 号 |

### 数据与队列

| 变量 | 说明 |
|------|------|
| `REDIS_HOST` / `REDIS_PORT` | Redis 地址与端口 |
| `AGENT_QUEUE_NAME` | 任务队列名,默认 `agent_tasks` |
| `AGENT_WORKER_STATUS_KEY` | worker 状态 Key,默认 `aagent:worker:status` |
| `MONGO_HOST` / `MONGO_PORT` / `MONGO_USER` / `MONGO_PASS` | MongoDB 连接信息 |
| `MONGO_DATABASE` | 数据库名,默认 `agent` |
| `MONGO_HISTORY_COLLECTION` | 历史集合名,默认 `event_history` |

## 2. Docker Compose

5 个服务:`agent` / `qqbot` / `webui` / `redis` / `mongodb`,自定义桥接网络 `rainbow_net`。

常用命令:

```powershell
docker compose up --build -d      # 构建并启动
docker compose logs -f agent qqbot # 跟踪日志
docker compose down                # 停止(运行时数据保留在 data/)
```

注意:`mongodb` 将容器内 `27017` 映射到宿主机 `27015`;`redis` 映射 `6379`;`webui` 映射 `8080`。

## 4. 安全注意事项

1. `.env` 含真实密钥,务必确认已加入 `.gitignore` 且未被提交;
2. `agent/script.py`、`agent/2.py`、`agent/3.py` 中**硬编码了真实 API Key**,生产环境必须删除或改为从环境变量读取;
3. MongoDB 使用 root 账号,建议为应用创建最小权限独立用户;
4. Redis 无密码,公网部署建议启用 `requirepass` 并限制网络访问。
