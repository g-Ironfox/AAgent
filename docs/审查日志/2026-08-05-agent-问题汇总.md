## 4. 已核验正确项(无需改动)

- 插队链不打断:RPUSH 插队 + BRPOP 队尾消费,一次 RPUSH 实现工具链优先;
- 多 tool_calls 反转入队:`events[::-1]` 抵消 RPUSH 多参方向性,工具按 LLM 声明顺序执行;
- 一鱼多吃的历史管线:同一 `record_history` 服务 LLM 上下文、WebUI 监控、工具追踪;
- 事件脉冲:worker 空闲即阻塞 BRPOP,无空闲轮询、无额外定时器;
- 队列语义:LPUSH 普通排队 / RPUSH 优先插队 / BRPOP 尾部消费,重构后无回归;
- `deepseekBalance` 的 `/v1/user/balance` 拼写已由用户确认正常,勿改;
- `send_private_msg` schema `required` 已修对(`["user_id","message"]`);
- 投影格式 `<Command>...</Command>` 与 `settings.json` 默认种子一致;
- `utils.env()` 语义正确(`os.getenv(name) or fallback`,空串回退)。

## 5. 部署与安全(agent 相关)

- Redis 当前无密码;公网部署必须启用认证并限制网络访问(启用时需同步 A18 三处);
- MongoDB 当前使用 root 账号,应创建最小权限应用用户;
- `.env`、运行数据与曾泄露的密钥不得进入版本库;
- agent 启动期 Redis 硬依赖(`initialize_system_prompt()` 在 `while True` 之外):Redis 抖动时可能 crash loop(compose health 门控缓解),见 [设置落 Redis 审计报告](2026-08-06-settings-redis-审计报告.md);
- dev 模式注意:本地直接改 `agent/settings.json` 默认种子后重启容器会被 Redis 设置覆盖(`initialize_system_prompt` 恢复 Redis 值);要回退默认需先删除 Key `aagent:settings` 再重启 agent。
