## 维护规则

1. 审查报告使用 `YYYY-MM-DD-主题.md` 命名,完成后不回写成实时说明;
2. 尚未解决的问题统一汇总到"2026-08-02 审查核验汇总",修复后从汇总删除;
3. 稳定且仍生效的设计结论应提炼到上级核心文档,日志只保留决策背景与专题设计;
4. 日志与核心文档冲突时,先核对源码,再修正核心文档和审查核验汇总。
