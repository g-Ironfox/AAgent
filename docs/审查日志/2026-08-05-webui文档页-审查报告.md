## 2. 已核验的正确性

### 2.1 后端(`webui_py/main.py`)

1. **存储隔离正确**:文档使用独立 `documents` 集合(`MONGO_DOCUMENT_COLLECTION` 可覆盖),不写入 `event_history`,不进入事件流与 LLM 上下文;复用既有 `MongoClient`(`tz_aware=True`),时间统一 `datetime.now(timezone.utc)`;
2. **请求模型防御**:`DocumentRequest` 用 `ConfigDict(extra="forbid")` 拒绝未知字段;标题 `strip()` 后非空、最长 200 字符;正文最长 1,000,000 字符;请求体经中间件按 `Content-Length` 限制 1 MB;
3. **ID 校验**:`document_id()` 捕获 `InvalidId` 返回 `400`,避免 500;文档不存在统一 `404`,`PyMongoError` 统一 `503` 中文提示;
4. **更新语义正确**:`find_one_and_update(..., return_document=True)` 返回更新后文档;`$set` 仅改 `title/content/updated_at`,保留 `_id` 与 `created_at`;目标已被删除时返回 `None` → `404`;
5. **路由顺序正确**:精确路由 `GET /api/documents` 定义于带参路由之前;所有文档路由位于 `app.mount("/")` 静态挂载之前,不会被静态文件接管;
6. **列表契约轻量**:`GET /api/documents` 只投影 `title/created_at/updated_at`(不含正文),按 `updated_at` 降序,前端点选后再取正文。

### 2.2 前端(`document.js`/`document.html`/`document.css`/`api.js`)

7. **脏状态比较**:`isChanged()` 以已保存快照对比当前输入(标题 trim、正文保留空白),无变化时保存按钮禁用,不产生请求;
8. **未保存保护**:切换文档、新建、删除前均以 `confirm` 提示未保存修改;删除二次确认;
9. **预览随输入实时更新**:`content` 的 `input` 事件同步 `preview.textContent`,编辑/预览模式切换不丢失输入;
10. **XSS 安全**:标题/正文/预览全部走 `.value`/`.textContent`,无 `innerHTML` 注入;预览为纯文本,不解析 Markdown;CSP 未被破坏;
11. **防连点与禁用态**:`loading/saving` 期间禁用列表、输入、按钮与模式切换;`AbortError` 与后端错误分别提示;输入即清除旧错误状态;
12. **列表身份稳定**:列表项以 MongoDB ObjectID 字符串为身份,`active` 高亮与详情一一对应,保存/删除后列表正确重排;
13. **边界一致**:标题 `maxlength=200`、正文 `maxlength=1000000` 与后端上限一致;字符计数按码点 `[...value].length` 统计,CJK 正确。

## 3. 问题清单

| 级别 | 问题 | 说明与建议 |
|------|------|-----------|
| **P1(已修复)** | **`.document-empty` 的 `display:grid` 覆盖 `hidden` 属性,占位层常驻并遮挡编辑区** | 作者样式优先级高于 UA 的 `[hidden]{display:none}`,打开文档后“选择一篇文档”仍显示且 `position:absolute; inset:0` 拦截点击。已补 `.document-empty[hidden]{display:none}`(见实现记录第 7 节) |
| P3 | 文档列表无分页/上限 | `GET /api/documents` 返回全部文档;个人文档库可接受,量大时建议加分页或上限 |
| P3 | `documents.updated_at` 无索引 | 降序排序为全集合扫描;文档量大时建议补索引并验证 |
| P3 | 预览为纯文本,不支持 Markdown | CSP 禁止 CDN,如需 Markdown 需将解析器打包为本地静态文件 |
| P3 | 无 `beforeunload` 未保存提示 | 刷新/关闭页面时未保存修改直接丢失;可在脏状态时注册 `beforeunload` |
| P3 | 列表无自动刷新/多标签同步 | 两个标签页同时编辑无实时一致;非必需,可后续加轮询 |
