## 1. 领域现状

五个服务(agent / qqbot / qqbot_consumer / webui_py / workflow_editor)通过 Redis 队列与 MongoDB 共享状态,但它们之间**没有任何共享代码**:队列客户端、LLM 客户端、历史仓储、工具注册表、节点契约常量各自复制。事件格式与队列取序语义靠各服务手写 dict 与 `lpush`/`rpush`/`blpop`/`brpop` 的方向配对维持。所有 HTTP 接口无鉴权。运行时的 LLM 上下文完全由画布决定,旧的事件驱动链(`active`/`tool_excute`)已无生产者但代码与周边能力仍在。
