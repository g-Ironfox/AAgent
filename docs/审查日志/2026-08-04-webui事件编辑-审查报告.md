# 2026-08-04 WebUI 事件编辑审查报告

> 审查对象:2026-08-04 WebUI 事件编辑功能(`PUT /api/events` + 前端编辑/保存/取消)。本文件是历史快照,当前行为以源码与[前端API格式](../webUI/前端API格式.md)为准;未解决问题统一登记在[2026-08-02 审查核验汇总](2026-08-02-审查核验汇总.md)第 4 节。实现范围见[2026-08-04-webui事件编辑-实现记录](2026-08-04-webui事件编辑-实现记录.md)。

## 1. 审查结论

**通过(有条件)**。功能完整、契约自洽、并发处理正确,与既有 delete/快照逻辑复用同一套指纹与位置约定。建议处理 2 个 P2 项后再交付。

## 2. 已核验的正确性

### 2.1 后端(`webui_py/main.py`)

1. **指纹一致性**:`update_event` 返回的 `fingerprint` 用 `event_fingerprint(event)`(剔除 `_id`/`created_at`、键排序、紧凑分隔符)计算,与 `history_stage`/`pending_stage` 的指纹算法一致,前端 remap 后下一轮快照必然命中;
2. **pending 位置语义正确**:`position` 为"距队尾距离"(`pending_stage` 中 `len(raw_items) - index`),`lindex(-position)` 定位正确,与 delete 完全同构;
3. **Redis 原子更新**:Lua 脚本先 `LINDEX` 比对原始串再 `LSET`,消除读-改-写窗口;`409`/`404` 分支正确;
4. **防御性校验**:服务端再次剔除 `_id`/`created_at`;`event_type` 非空校验;256 KB 在中间件(Content-Length)与内容编码后双重限制;
5. **`replace_one` 保留元数据**:Mongo 在替换文档不含 `_id` 时保留原 `_id`;`created_at` 从旧文档取回,与既有 `{**event, created_at}` 存储结构一致;
6. **中间件重构无回归**:`(method, path)` 元组键对既有路由行为等价,新增 PUT 无副作用。

### 2.2 前端(`render.js`/`app.js`/`api.js`)

7. **无变化不提交**:`canonicalJson` 递归键排序比较,语义等价(数组顺序保留、键顺序忽略)才判定未变;格式错误在 `JSON.parse` 阶段拦截,不产生请求;
8. **编辑态不被轮询破坏**:`updateEventRow` 对 `editing` 行提前返回,不覆盖输入;`row._item` 仍刷新,保存时使用最新指纹/位置;
9. **展开状态保持**:`expandedKeys` 用稳定身份(done→doc_id,pending→fingerprint+position),`remapExpandedKey` 处理指纹变化,刷新后正确恢复;
10. **XSS 安全**:编辑框走 `.value`、只读详情走 `.textContent`,无 innerHTML 注入;CSP 未被破坏;
11. **错误状态闭环**:无效 JSON/保存失败红字+红框,输入即清除,取消/成功也清除;
12. **防连点**:保存期间 `button.disabled`,避免重复提交。

## 3. 问题清单

| 级别 | 问题 | 说明与建议 |
|------|------|-----------|
| **P2** | **编辑中的事件被消费/移出窗口时,编辑内容静默丢失** | `editing` 类只保护 `updateEventRow`,不保护 `renderSection` 的节点移除。编辑 position 1 的 pending 事件时,Worker 一旦 `BRPOP` 消费,该行直接移除,输入丢失。建议在 `renderSection` 移除节点前检测 `editing` 状态,提示"该事件已开始执行,编辑已取消" |
| **P2** | **非 Chromium 浏览器编辑框内容不可达** | `field-sizing: content` 仅 Chromium 支持。Firefox/Safari 下 textarea 用 UA 默认高度(约 2 行),配合 `overflow: hidden` 后长 JSON 被裁剪且无法滚动。建议补 `@supports not (field-sizing: content)` 兜底(固定高度 + `overflow: auto`) |
| P3 | `replace_one` 未检查 `matched_count` | find 与 replace 之间若被删除,仍返回 200;可加 `matched_count == 0` 时返回 404 |
| P3 | `expandedKeys` 无回收 | 已删除/滚出窗口的 key 长期驻留 Set,会话内微量内存增长;可在节点移除时同步清理 |
| P3 | 保存后若恰逢轮询在途,最多 2s 内显示旧数据 | `refresh()` 遇 `state.loading` 直接跳过,在途旧快照先渲染,下一轮自愈;与 delete 同款既有行为 |
| P3 | PUT 共用 5s 超时 | `api.js` 所有请求共用 `FETCH_TIMEOUT_MS = 5000`,接近 256 KB 的大事件在慢网络下可能超时;事件通常很小,可接受 |
| P3 | 无键盘快捷键 | Esc 取消 / Ctrl+Enter 保存未实现,锦上添花 |

> 注:FastAPI 422 返回 `{"detail":...}` 破坏 `{"error":...}` 契约,PUT 同样继承,属既有已知问题(已登记核验汇总 P1),非本次新增。
