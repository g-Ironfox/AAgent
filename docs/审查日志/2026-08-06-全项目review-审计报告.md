## 2. 已核验

### 2.1 架构与正确性(与设计一致)

1. **队列语义**:`BRPOP` 队尾消费 + `LPUSH` 普通排队 / `RPUSH` 插队,工具链 `response→tool→tool_return→active` 不被新消息打断;
2. **多 tool_calls 顺序**:`events[::-1]` 反转入队抵消 RPUSH 多参方向性,工具按 LLM 声明顺序执行;
3. **统一管线**:所有事件先 `record_history()` 再按 `handle_map` 分发;
4. **事件编辑原子性**:`PUT/DELETE /api/events` 的 Lua 脚本 + 指纹校验,409/404 分支齐全;
5. **WebUI 安全面**:安全响应头、CSP、前端无 `innerHTML` 注入、`extra="forbid"` 模型;
6. **设置链路**:`settings.json` 种子 → Redis 单键 `aagent:settings`,与 2026-08-06 settings-redis 审计一致;
7. **仓库状态**:git 工作区干净(HEAD=`e995185`),VS Code 诊断零错误。

## 3. 问题清单(新增发现)

| 级别 | 问题 | 说明与建议 |
|------|------|------------|
| P0 | **N1 未授权消息进入 LLM 上下文** | 三段链路:① `qqbot/listener.py::parse_event` 对任何含 `user_id` 的消息都投递,无鉴权过滤;② `task_worker.py::handle_task` 对 `qq` 事件无条件 `record_history()`,鉴权判断在落库之后;③ `active` 投影对历史中所有 `qq message` 事件不加 `user_id` 过滤拼进 LLM 上下文。结果:群内陌生人消息、他人私信会被写入 MongoDB 并进入下一轮 LLM 上下文,既污染上下文也是提示注入向量,与 `settings.json` 种子"任务与目标只有管理员的命令"冲突。建议:投影时按 `user_id == TARGET_USER_ID` 过滤,或在 `record_history` 前过滤非授权消息 |
| P1 | **N2 WebUI 完全无鉴权** | 全部写接口(`POST /api/terminal`、`POST /api/settings/system-prompt`、`PUT/DELETE /api/events`、文档 CRUD)均无认证;docs/08 定义 terminal 为"最高权限入口",W11 仅列为 P4,严重度被低估。8081 暴露到非 localhost 时,任何人可注入 system prompt、提交终端命令、删改事件历史与文档。建议:反向代理 + Token 鉴权,或明确"仅限本机/内网"边界并写入 docs/04 安全检查清单 |
| P1 | **N3 工具链无迭代上限** | `response→tool→tool_return→active` 循环无最大轮次保护;LLM 持续返回 tool_calls 时(模型故障或 prompt 诱导)会无限循环调用工具,执行与 token 费用失控。建议:`active` 分支加单条链迭代计数(如 5~10 轮),超限强制产出最终回复 |
| P2 | **N4 `prompt/skills/` 整目录死资产** | `agent/prompt/skills/` 下 6 个技能文件(傲娇 v2/v3、现实、不在三代之内)从未被任何代码加载,`task_worker.py` 中 `skills=[]` 为硬编码空列表;文件名不一致(`skills_傲娇v3.md` vs `skill_傲娇v2.md`)。建议:接入 `active` 分支真正注入,或删除并清理引用 |
| P2 | **N6a `llm.py::chat_with_llama_cpp` 死代码** | `task_worker.py` 导入但从未调用,硬编码 `http://127.0.0.1:8080`。建议:删除或登记为预留并去 import |
| P2 | **N6b `tools/tool.py::bocha_search` 死代码** | 未注册、无调用方,还连带导入期强读 `BOCHA_*` 阻塞启动(A6)。建议:删除或注册为工具 |
| P3 | **N6c `active` 分支空 user 消息** | 每轮附加 `{"role":"user","content":""}`(`"\n".join(skills)` 为空串),白白发给 LLM。建议:`skills` 为空时跳过该消息 |
| P3 | **N5 文档漂移 `limit=16` vs `limit=10`** | `task_worker.py:131` 用 `get_recent_history(limit=16)`,docs/03、06、07 均写 `limit=10`;docs/03 §4 投影归属仍写 `llm.py`(实际在 `task_worker.py`,A40 未完全修干净)。建议:同步代码与文档 |
| P3 | **N7 配置模板缺口(已修复)** | `.env.example` 缺 `AGENT_SETTINGS_KEY`/`REDIS_PASSWORD`/`REDIS_DB`/`MONGO_DOCUMENT_COLLECTION`(docs/04 有文档但模板缺失)。已补全模板并同步 docs/04 §3.2;注意启用 Redis 认证仍需先完成 A18(agent/qqbot 未读 `REDIS_PASSWORD`) |
