# 2026-08-05 WebUI 文档页实现记录

> 本文记录 2026-08-05 WebUI 文档管理功能的实现范围、关键决策与静态验证结果。它是特定时间点的实现快照；当前接口契约以源码为准。

## 1. 目标与范围

WebUI 新增“文档”页面，用于创建、浏览、编辑和删除用户文档：

- 页面采用左右工作区布局：左侧为按更新时间倒序排列的文档列表，右侧为编辑/预览区域；
- 文档可新建、选择、修改、保存与删除；切换或新建前检测未保存修改；
- 正文预览为安全的纯文本预览，不解析 Markdown 或插入 HTML；
- 数据直接保存至 MongoDB 独立集合，不进入 Agent 事件队列，也不混入 `event_history` 历史上下文。

## 2. 存储与后端实现

`webui_py/main.py` 新增 `MONGO_DOCUMENT_COLLECTION` 配置，默认集合名为 `documents`，并复用 WebUI 已有的 MongoDB 客户端。

每篇文档结构为：

```json
{
  "_id": "ObjectId",
  "title": "文档标题",
  "content": "正文",
  "created_at": "UTC datetime",
  "updated_at": "UTC datetime"
}
```

新增接口：

| 接口 | 行为 |
|---|---|
| `GET /api/documents` | 返回左侧列表需要的 ID、标题和时间，不返回正文；按 `updated_at` 降序排列。 |
| `POST /api/documents` | 创建文档并返回完整内容。 |
| `GET /api/documents/{id}` | 返回单篇文档正文。 |
| `PUT /api/documents/{id}` | 更新标题、正文与 `updated_at`。 |
| `DELETE /api/documents/{id}` | 删除指定文档。 |

请求模型拒绝未知字段。标题经 `strip()` 后不能为空，最大 200 字符；正文最大 1,000,000 字符；文档创建和更新请求体最大 1 MB。非法 ObjectId 返回 `400`，不存在的文档返回 `404`，MongoDB 异常返回 `503` 和中文错误信息。

`docker-compose.yml` 为 `webui_py` 增加 `MONGO_DOCUMENT_COLLECTION: ${MONGO_DOCUMENT_COLLECTION:-documents}`，允许部署时调整集合名称。

## 3. 前端实现

新增以下文件：

- `webui_py/static/document.html`：文档页面骨架和四项主导航；
- `webui_py/static/document.js`：列表加载、详情读取、新建、保存、删除、脏状态提示和编辑/预览切换；
- `webui_py/static/css/document.css`：两栏工作区、列表选中态、编辑器、移动端单栏布局；
- `webui_py/static/api.js`：文档 CRUD 请求封装，沿用现有 5 秒 AbortController 超时和统一错误解析。

事件流、终端和设置页的导航均新增 `/document.html` 入口。小屏幕下工作区切换为上下布局，避免左右栏压缩编辑区。

## 4. 涉及文件

- `webui_py/main.py`：文档集合、请求模型、长度限制和 CRUD 接口；
- `webui_py/static/api.js`：文档 API 客户端；
- `webui_py/static/document.html`、`document.js`、`css/document.css`：文档页面；
- `webui_py/static/index.html`、`terminal.html`、`setting.html`：导航入口；
- `docker-compose.yml`：文档集合环境变量。

## 5. 验证结果与边界

- VS Code 对本次涉及的 Python、JavaScript、HTML、CSS 和 Compose 文件的诊断均为零错误；
- 已静态核对新页面文件、导航链接、`/api/documents` 路由和 MongoDB 集合配置的引用关系；
- 本机没有 WebUI 所需的 Docker 运行环境，未执行真实 MongoDB 的接口集成测试，也未进行浏览器端手工交互测试；
- `python -m py_compile` 与 `node --check` 的命令行静态检查曾被终端侧取消，未取得命令行输出；
- 尚未创建 `updated_at` 索引。若文档数量增长，应在 `documents.updated_at` 上补充降序索引，并验证列表查询性能。

## 6. 部署说明

生产 Compose 不挂载本地 `webui_py` 源码。部署本次变更时需要重新构建并启动 WebUI 容器：

```powershell
docker compose up -d --build webui_py
```

完成后访问 `http://localhost:8081/document.html`。开发 Compose 是否即时加载后端改动取决于 Uvicorn 启动参数；静态前端文件在源码挂载时可通过浏览器刷新加载。

## 7. 复查补充（2026-08-05）

- **缺陷修复**：`.document-empty` 的 `display:grid` 会覆盖浏览器对 `hidden` 属性默认的 `display:none`，导致打开文档时占位层仍显示并遮挡编辑区；已增加 `.document-empty[hidden]{display:none}`；
- **契约补齐**：按惯例将文档 CRUD 接口契约补入 [`docs/webUI/前端API格式.md`](../webUI/前端API格式.md) 第 7 节；
- **复查结论**：无 P0/P1 遗留；保留的 P3 项为：文档列表无分页上限、`documents.updated_at` 无索引（量大时需补）、预览为纯文本（如需 Markdown 需本地打包解析器，不能使用 CDN）。
