# 05 已知问题与优化建议

> 更新日期:2026-07-31。基于当前代码仓库状态梳理。

## 1. 代码质量

1. **测试脚本含硬编码密钥**:`agent/script.py`、`agent/2.py`、`agent/3.py` 直接写入 API Key,存在泄露风险。
2. **异常处理较粗糙**:部分接口调用未做细粒度异常分类与重试,网络抖动时可能导致任务失败。

## 2. 业务逻辑

1. `/search` 命令仅返回第一条结果的标题,建议返回摘要/链接或支持结果数量选择。
2. `bocha_search` 已定义但未注册到 `tools`,LLM 无法主动调用。
3. **无幂等与去重**:Redis 任务重复投递或 LLM 生成重复事件可能导致重复回复。

## 3. 部署与安全

1. MongoDB 使用 root 账号,建议创建最小权限独立用户。
2. Redis 当前无密码,公网部署建议启用 `requirepass` 并限制网络访问。
3. 建议增加健康检查与日志轮转,便于长期稳定运行。
